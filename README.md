# Ice Cream Brand Intelligence Assistant

Ask business questions about an ice cream brand in plain language. Answers come from the brand's own documents (vectorless RAG with [PageIndex](https://github.com/VectifyAI/PageIndex)) and sales data (SQL on DuckDB), with citations and exact numbers.

**Stack:** LangChain · LangGraph · LangSmith · PageIndex · DuckDB · FastAPI
